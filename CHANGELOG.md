# Changelog

## 0.1.0-preview

Initial public preview for Windows 11 x64.

- Native tray, quick panel and dashboard for configurable Linux SSH targets.
- Password/private-key authentication, one jump host, explicit host-key verification and DPAPI credential storage.
- Bounded collection, minute history, resource/offline/expiry alerts and JSON import/export.
- Chinese UI with system/light/dark themes and centralized strings.
- English default documentation with Chinese translations, MIT license, reproducible build and synthetic test tools.
- Published short performance measurements. The uninterrupted eight-hour soak, high-latency fleet and physical power/display/notification acceptance tests remain pending; this is not a stable release.
