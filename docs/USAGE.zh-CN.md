# 使用说明

## 添加与管理

添加服务器时填写显示名称、SSH 地址、端口和用户名。在“SSH 连接”中选择密码或加载私钥；私钥会被加密保存，不再依赖原文件路径。编辑时密码或口令留空保留原值。支持 SSH.NET 可读取的 OpenSSH/PEM RSA、Ed25519 和 ECDSA 密钥；RSA 使用 SHA-2 签名。

第一次连接停在“需要核验主机密钥”。点击“核验主机密钥”，通过可信渠道比对指纹再确认。主机重装等情况下密钥变化会再次拦截。跳板与目标分别核验、分别认证，不进行 Agent 转发。跳板必须先配置，且不能再使用其他跳板。

服务器可按分组、名称或标签搜索；详情的上、下按钮修改顺序。在编辑器中停用监控或删除配置。被其他主机使用的跳板不能直接删除。

## 采集与告警

默认 15 秒采集、10 秒超时、4 个并发；静态信息连接时读取，根盘空间每 60 秒读取。接口筛选先应用包含规则，再应用排除规则。首个样本和计数重置后无法计算速率，显示为“—”。磁盘 I/O 为常见物理/虚拟整盘计数之和，不是应用或指定挂载点的 I/O。

全局规则可由服务器单独覆盖，CPU、内存、根盘各有独立开关。默认 CPU 85%、内存/根盘 90%，持续 120 秒提醒；低于阈值减 5 个百分点持续 60 秒恢复。离线须超过 75 秒或 3 个采样周期中较长的一项。认证失败、主机密钥、网络/命令超时和采集错误分别标记。到期提醒不依赖连接成功。

网络断开时汇总提醒，恢复后重新获取当前状态。启动、唤醒及本机网络恢复后约 60 秒汇总当前需关注的服务器，不补发历史通知；平时相邻 3 秒内的事件合并通知。启动、唤醒和断线会重置连续时长判断，避免将数据空缺计入持续高负载。通知是否弹出还取决于 Windows 通知和专注设置；事件会保留在程序内。

## 配置与数据

默认数据目录是 `%LOCALAPPDATA%\ServerTray`，包括配置及其上一份备份、加密凭据、可信主机指纹、历史数据库、告警状态和两份最多约 1 MiB 的滚动日志。程序运行不需要写入 EXE 所在目录。

导出 JSON 不包含凭据。服务器地址、用户名、分组和标签仍是配置的一部分，请在公开分享前检查。导入会预览新增、删除和修改数量，再替换配置；改变连接身份的主机不复用之前保存的凭据。跨电脑迁移后需要重新填写凭据、重新核验指纹。

`schemaVersion` 当前为 1。缺省字段使用当前默认值；未来版本和未知字段会被拒绝，不会静默丢弃。无效配置启动时保留原文件并提示错误，可以检查 `config.json.bak` 后手动恢复。示例文件仅包含虚构目标，建议先导入后在界面修改。

历史按分钟汇总，UTC 存储，默认保留 7 天，可调 1～30 天。程序离线期间没有样本，图表保留断点。额外最多保存最近 100 万条分钟记录，超过时清理最旧数据。每次查询最多 1200 点。

## 托盘与命令行

单击托盘显示速览，双击打开主窗口。绿色表示连接正常，黄色表示连接或资源需关注，灰色表示本机网络不可用。悬停可显示全局在线数量或当前选中服务器。

```text
ServerTray.exe --minimized
ServerTray.exe --data-dir "D:\MyServerTrayData"
ServerTray.exe --demo --data-dir "D:\ServerTrayDemo"
```

相同用户与数据目录只运行一个实例，再次启动会唤起已有窗口。`--demo` 使用虚构数据，不访问服务器；请给演示使用独立数据目录。普通启动没有配置时显示引导，不预设任何连接。
